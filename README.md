# Сенсорика — сайт творческой мастерской

Одностраничный сайт мастерской «Сенсорика» (Чебоксары): гончарный круг, лепка, гипс, свидания и детские праздники. На первом экране интерактивная 3D-игра на Three.js с выбором занятия: слепить изделие на гончарном круге или расписать готовую заготовку (кружку, подсвечник-стакан, вазу, тарелку, картину, неваляшку или матрёшку): кисти, орнаменты и символы-штампы (и на вазе с круга, и на заготовках), а у заготовок ещё надпись, в том числе дугой по кругу тарелки. Потом обжечь в печи, повернуть готовое изделие удачной стороной (стрелками или перетаскиванием) и сохранить фото.

Статический сайт без сборки: HTML, CSS и JavaScript открываются как есть.

## Структура

| Путь | Что там |
|---|---|
| `index.html` | страница |
| `css/styles.css` | стили |
| `data/site.js` | **контакты, цены, услуги** — менять здесь |
| `js/main.js` | наполнение страницы из `data/site.js`, заголовок дугой |
| `js/game.js` | 3D-игра: гончарный круг и роспись заготовок |
| `js/music.js`, `assets/audio/warm-clay.mp3` | фоновая музыка «Тёплая глина» (сгенерирована Suno), кнопка с нотой в шапке |
| `assets/vendor/three.min.js` | Three.js r159 |
| `assets/fonts/` | шрифты (woff2, кириллица и латиница отдельно) |
| `assets/img/`, `assets/plates/`, `assets/illustrations/` | картинки в WebP |
| `DESIGN.md`, `PRODUCT.md` | дизайн-система и описание продукта |

## Как поменять цены и контакты

Откройте `data/site.js`, исправьте значения и сохраните. Если у поля стоит `null`, на сайте покажется пометка «уточняется».

## Запуск локально

Можно просто открыть `index.html` в браузере. Или поднять локальный сервер:

```
python -m http.server 8000
```

и открыть http://localhost:8000. Фоновую музыку Chrome со страницы, открытой с диска, не загружает — её проверяют через сервер.

## Публикация на GitHub Pages

1. Создайте на GitHub пустой репозиторий (например, `sensorika`).
2. В папке сайта:
   ```
   git remote add origin https://github.com/<логин>/sensorika.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
4. Через минуту сайт откроется по адресу `https://<логин>.github.io/sensorika/`.

Свой домен подключается там же, в поле **Custom domain**.

## Скорость на телефоне

- Все картинки в WebP, с `srcset`: телефон скачивает уменьшенные версии.
- Three.js (~650 КБ) грузится после картинок первого экрана, страница появляется раньше.
- Шрифты первого экрана подгружаются заранее (`preload`).
- На телефонах 3D-сцена рендерится с меньшим разрешением и лёгкими тенями.
- При самом первом входе 4 секунды показывается заставка (гончарный круг с вазой), пока грузятся 3D и фото; дольше 9 секунд она не держится. Повторно не показывается, даже после обновления страницы.
- Прогресс игры (занятие, форма или заготовка, этап, роспись с надписями) хранится в браузере 7 дней: если страница перезагрузилась, изделие остаётся на месте. Кнопка «Начать сначала» возвращает к выбору занятия.
- Для проверки этапов без прохождения игры: `?demo=lump|shape|paint|fire|done` (гончарный круг) и `?demo=pick-mug`, `paint-plate`, `done-candle`… (заготовки: `mug`, `candle`, `vase`, `plate`, `picture`, `roly` — неваляшка, `doll` — матрёшка). В режиме `demo` прогресс не сохраняется.
- Пункты меню прокручивают к разделу, не дописывая якорь в адрес: иначе `#gift` после «Сертификатов» оставался в истории браузера, и следующий вход открывался на сертификатах. Новый вход всегда начинается с игры; якорь из адреса (`…/#prices`) работает, только если по ссылке пришли с другого сайта, например из поста во ВКонтакте.
- При обновлении страницы она остаётся на том же месте: позицию прокрутки запоминает `js/main.js` (в пределах вкладки). Если вкладку открыли спустя полчаса и больше (телефон выгрузил её из памяти), это считается новым входом.
- После загрузки игры фото ниже по странице докачиваются заранее, чтобы при прокрутке они уже были на месте.
- Фоновая музыка (~2 МБ, MP3 80 кбит/с) скачивается только когда начинает играть: с первого касания игры или по кнопке с нотой в шапке. Трек идёт по кругу внахлёст: последние 8 секунд затихают, пока начало нарастает, поэтому стык не слышен. Выключенная кнопкой музыка сама больше не включается (выбор хранится в браузере); в режиме экономии трафика она тоже ждёт кнопки. Пока вкладка скрыта, звук на паузе.

Исходные PNG/JPG в репозиторий не входят (см. `.gitignore`). Чтобы заменить картинку, сохраните новую в WebP (качество ~80) под тем же именем.
